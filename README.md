# Ứng dụng đặt xe và giao đồ ăn

Repository Android/Kotlin độc lập, thuộc tài khoản duyuyd. Không phải NuvoraCraft hay Góc Hợp Âm; giữ nguyên tên, package ID và chức năng đặt xe.

## Chuẩn hóa GitHub 48.0

Quét nhãn thương hiệu cũ trên nhánh `feat/auto-standardization`, giữ nguyên đường dẫn kỹ thuật và mã Android. Không áp dụng Capacitor vì dự án không dùng Next.js. Mọi thay đổi được xem xét trong Pull Request trước khi merge.
